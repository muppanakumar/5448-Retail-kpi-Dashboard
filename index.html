    How this prototype works

    A store-level sales feed pushes one JSON message per second over a socket. The first message after connecting is a full snapshot; every later message is a small delta with a sequence number. If the browser sees a gap it asks for a new snapshot, and if the link drops it reconnects with exponential backoff (1, 2, 4, 8 seconds) and reloads state. Try the Drop connection button.

    • The feed here is simulated inside the page by MockSocket, because published pages cannot open outside connections. In your own deployment, replace new MockSocket() with new WebSocket("wss://your-host/stream") and keep the same message shapes.
    • One store-day is compressed into 12 real minutes (1 second is 1 store minute). Sales volumes, category weights and the daily demand curve are illustrative. They are not taken from a government dataset.
    • Alerts compare each store's last 5 minutes with the 40 minutes before. A ratio above 1.8 raises a surge, below 0.45 raises a dip.
    • The question box uses simple rules to write SQL. A production version would send the question and table schema to a language model and run the returned query on the warehouse.
    • The page is responsive and respects phone safe areas. Installing it as a PWA needs a manifest and service worker served from your own origin.
